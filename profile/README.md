## Meet Pika H3 Flex

Generate video with synchronized audio in **six neural function evaluations (NFEs)**. Create with text prompts, first- and last-frame conditioning, or multimodal references.

**[Try the demo →](https://huggingface.co/spaces/Pika-Labs/pika-h3-flex)**
