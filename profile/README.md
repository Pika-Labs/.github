# Pika Research

We build video and audio models for creative expression, turning frontier research into new ways to create.

## Featured release: Pika H3 Flex

Pika H3 Flex generates video with synchronized audio, with support for text prompts, first/last-frame conditioning, and multimodal references. It uses six neural function evaluations (NFEs) for generation.

- **[Try the demo](https://huggingface.co/spaces/Pika-Labs/pika-h3-flex)**
- [Inference code and quickstart](https://github.com/Pika-Labs/Pika-H3-Flex)
- [Model weights](https://huggingface.co/Pika-Labs/Pika-H3-Flex)
- [Technical deep dive](https://pika.art/blog/pika-h3-flex-research)
- [ComfyUI tutorial](https://docs.comfy.org/tutorials/video/pika/pika-h3-flex)
- [Diffusers documentation](https://huggingface.co/docs/diffusers/main/en/api/pipelines/pika_h3_flex)

See the model documentation for examples, hardware requirements, licensing, and the differences between local inference and hosted API capabilities.
